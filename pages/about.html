Cunoaște trainerii care îi pregătesc pe cursanții IT School pentru o carieră în IT.

Antonio Nemțișor

Software Developer

Antonio este Software Developer cu peste 6 ani de experiență. Tehnologiile lui preferate sunt JavaScript, React și Node.js. Un aspect amuzant despre el este că atunci când merge la mecanic este pentru că a încercat să-și repare singur mașina. Antonio consideră că domeniul în care lucrează este foarte frumos, cu oameni extraordinari și că este foarte important să-ți placă ceea ce faci deoarece vei avea mereu ceva nou de învățat.
